# Brasily JS

**Brasily JS** é uma biblioteca JavaScript leve e intuitiva, que une a elegância das cores vibrantes do Brasil a uma abordagem minimalista para desenvolvimento web. Ela oferece um conjunto robusto de funções para manipulação de DOM, validação de dados, requisições AJAX e muito mais – tornando o desenvolvimento de aplicações web rápido e eficiente.

## Recursos

- **Utilitários para Inputs:** Obtenha e manipule valores de inputs, limpe campos e desative o autocomplete.
- **Manipulação de Elementos:** Selecione, clone e modifique elementos HTML com facilidade.
- **Gerenciamento de Classes e Atributos:** Adicione, remova e altere classes e atributos em elementos.
- **Eventos:** Vincule e remova eventos de forma prática.
- **Requisições AJAX:** Faça requisições GET e POST que retornam JSON de forma simples.
- **Parsing e Validação de Dados:** Converta tipos de dados e valide formatos (e-mail, CPF, CNPJ, URLs, etc.).
- **Function Builder:** Crie funções seguras com validação automática dos tipos de parâmetros e retorno.
